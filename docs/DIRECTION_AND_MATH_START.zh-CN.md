# 连续 SFT 的选择性更新与能力保留：方向与首批数学分析

日期：2026-10-08。状态：研究方向已收敛，开始概念与数学探索；以下三个记录是分析线索，不是已经通过经验验证或原创性审查的方法候选。

## 1. 主线与具体例子

主线：**时间上不断到来的多来源文本/示范，怎样通过连续 SFT 学到新知识，同时更新过时答案、保留历史事实、仍有效知识和未参与本轮训练的能力？**

这里的“时序”指文本按时间到来。以连续 SFT 为主要研究入口；时间增量 CPT 是知识更新的关联路线，之后可以检查 CPT→SFT 的影响。后者已经有相关研究，不能把这一流程本身当成创新。

下面是假想公司和教学情景，不是实验数据：

| 新数据与问题 | 理想行为 | 不良结果 |
|---|---|---|
| 原来知道甲是负责人；2026 年的新资料明确乙接任。问“现在谁负责？” | 答乙 | 为保持旧输出仍答甲 |
| 同时问“2024 年谁负责？” | 答甲 | 新资料覆盖了正确历史 |
| 公司成立年份未变 | 原答案继续正确 | 无关事实被改坏 |
| 接着只训练新领域问答，再要求数学解题、编程或严格 JSON | 原有能力尽量保留 | 未训练能力下降 |
| 下一批换成另一来源的新领域数据 | 已学领域与旧能力继续可用 | 每学一批就丢掉上一批 |

目标包含四种不同责任：吸收新信息、纠正过时的当前回答、保留历史和稳定知识、保留其他能力。只要求全部旧输出不变，会阻止合理更新；只看总平均分，又可能掩盖个别能力的下降。

为什么值得研究：同一条知识的“当前答案”和“历史答案”可能同时正确；新领域学习还可能影响与事实版本无关的推理、编程能力。需要弄清发生冲突的对象、原因和边界，才能决定训练应该改变什么。

## 2. 已知重合与初步边界

- **History Matters / AToKe / METO** 已研究时间知识更新及历史保留。本轮只读主论文摘要与版本信息，尚未完整检查实现。因此“加时间戳、保存历史答案”不是已确认的新贡献。
- **Multi-granularity Temporal Knowledge Editing / MTKE / SPIKE** 已研究不同时间粒度的更新。本轮只读 AAAI 出版页与摘要，正文、作者代码和原生数据尚未完成读取。
- **iSDFT** 已使用信息约束的局部蒸馏目标与固定初始模型 KL 锚，并包含连续学习实验。因此“移动教师之外再增加固定锚”应作为已有方法。
- **Sampling SFT** 的论文与作者代码审查见之前的专题笔记。把示范改写得更接近基础模型，是已有路线；分布接近的理论不能直接变成整个训练模型不会遗忘的保证。
- 之前审查的时间增量 CPT 与 Kairos 已涉及多轮时间更新、历史知识与重放。仅增加时间轮次、换指标或串联 CPT→SFT，不足以建立方法创新。

目前的剩余问题是探索性表述：**当新的、应当改变的事实与仍应保留的能力共同存在时，已有保护目标到底覆盖了什么，是否也会阻碍新信息进入？** 尚未证明这是强基线解决不了的自然失败，也尚未判定原创性。

## 3. 数学分析 A：保护旧输出何时阻碍合理更新？

问题：对同一输入前缀同时要求接近新目标和旧模型，会发生什么？

对象：固定前缀上的有限词表概率。令 q 为本次冻结的目标分布，p₀ 为旧模型，p 为自由待优化概率，a>0、μ≥0。分析：
\[
L(p)=a\,\mathrm{KL}(q\|p)+\mu\,\mathrm{KL}(p_0\|p).
\]
去掉与 p 无关的项：
\[
L(p)=C-\sum_v [a q(v)+\mu p_0(v)]\log p(v).
\]
加上归一化约束的拉格朗日乘子 λ，驻点满足：
\[
p(v)=\frac{a q(v)+\mu p_0(v)}{\lambda},\qquad \lambda=a+\mu.
\]
所以
\[
p^\star=\frac{a q+\mu p_0}{a+\mu}.
\]
当两分布为正时，交叉熵的凸性给出这个分布空间最优解。对“新正确答案”事件 F：
\[
\frac{\partial p^\star(F)}{\partial\mu}
=\frac{a[p_0(F)-q(F)]}{(a+\mu)^2}.
\]
若 q(F)>p₀(F)，提高保护强度会降低最优解给新答案的概率。若旧目标在此处依然正确，这种拉回可能有益。

操作与边界：math:D01→math:D02→权重敏感性。q 被冻结，p 是自由分布。实际 iSDFT 的目标会随学生改变，还有采样、重要性权重、共享参数、掩码和优化器；该推导不是完整训练轨迹，更不是 iSDFT 时间更新失败的实测证据。a 用来保留蒸馏项与保护项相对尺度的影响。

预测：在其他条件相同的局部模型中，保护旧的错误预测与保护仍有效预测的后果不同。可探索的问题是如何定义正确的保护对象，而不是无限增大统一保护系数。

竞争解释与否定条件：简单调低学习率、调节 μ、保留日期条件或既有时间编辑方法，就可能足够解决实际冲突。若它们已经满足目标，则没有开发新保护方法的必要。本恒等式是已知数学，不宣称新定理。

下一步：读取已有时间条件目标与强基线的实际实现，确定保护对象是否已经区分了版本。经验候选数量：0。

## 4. 数学分析 B：只在新领域上保持接近，能保护没见过的旧技能吗？

问题：如果保护损失只在新数据上计算，是否能推出旧能力也受保护？

对象：令 Qₜ 是保护项采样的输入/前缀分布，P_old 是想保护的旧输入/前缀分布；令
\[
d(x)=\mathrm{KL}(p_0(\cdot|x)\|p_\theta(\cdot|x))\ge0.
\]
假设 \(\mathbb E_{Q_t}d\le\varepsilon\)。若 P_old 对 Qₜ 绝对连续且密度比不超过 M，则
\[
\mathbb E_{P_{\rm old}}d
=\mathbb E_{Q_t}\!\left[\frac{dP_{\rm old}}{dQ_t}d\right]
\le M\varepsilon.
\]
这依赖覆盖与密度比，不能省略。

缺乏覆盖时的数学反例：只有两个输入 x_new、x_old；Qₜ 全部质量在前者，P_old 全部质量在后者。让两个模型在 x_new 完全相同，在 x_old 上分别输出 (1/2,1/2) 与 (η,1−η)。新域保护损失为零，而旧域 KL 在 η→0 时无界增长。

操作与边界：math:B03→math:H06。反例使用自由条件概率，反驳的是“单凭新域期望 KL 就能普遍保证旧域 KL”这一命题；不证明实际神经网络普遍发生这种变化。共享参数可能带来经验上的保护转移。KL 也不是原生任务准确率，仍需任务指标与必要条件。

实际源码联系：本轮读取的 iSDFT 损失在当前 prompt 加学生 completion 的前缀上计算固定模型锚，因此先要检查这些前缀对目标旧技能的覆盖，而非仅看锚系数。

预测：相同的新域保护损失，并不单独确定旧域保留效果；保护信息覆盖会影响能作出的保证。

竞争解释与否定条件：允许访问的旧增量数据重放、公开通用提示或既有蒸馏覆盖策略，可能已经足够。若现有简单策略解决实际问题，则不需要新方法。该覆盖界与反例不是新定理。

下一步：先明确能访问哪些旧增量数据与训练信息，再审查原生保留评价。不能把“原始预训练语料不可用”偷换成“禁止所有重放”。经验候选数量：0。

## 5. 数学分析 C：为贴近旧模型而改写，新事实会不会在训练前就丢失？

问题：若新示范被改写成旧模型更熟悉的表达，新实体、时间与变化事实是否还在？

对象：F 是新事实的随机变量，W 是初始模型信息，Q 是输入条件，E 是原始示范，Z 是改写后的示范。假设下游训练只接收 (W,Q,Z) 与独立训练随机性 U，输出参数 Θ；原始 E 没有另一路进入训练。

条件 Markov 关系 \(F\to Z\to\Theta\mid(W,Q)\) 给出：
\[
I(F;\Theta\mid W,Q)\le I(F;Z\mid W,Q).
\]
若改写后已不包含条件下的新事实信息，则只训练 Z 不能恢复被完全丢弃的信息。提高旧模型对 Z 的似然，与提高 Z 对 F 的信息保留，是不同的量。

操作与边界：math:B05 的条件化→信息传递/可识别性分析。条件数据处理不等式是已知结果，不是新定理。F 必须有明确的生成分布；本分析没有构造可用的经验互信息估计器，也没有把它当作新评价指标。若原示范同时进入训练，或 Q 本身携带新事实，上述信息输入必须重新定义。

预测：在确实存在改写信息损失的条件下，改写文本更符合旧模型并不保证新事实更容易学会。是否存在这种损失、发生多频繁，都需要真实数据证据。

竞争解释与否定条件：保持原文本、已有语义约束或时间条件改写，可能已经足够。若原生样本中事实与日期被可靠保留，且强基线没有相应缺口，这条线索应停止。

下一步：使用已有真实时间知识数据与其原生判定契约检查输入/输出，不编造评价题或自制语义裁判。阅读范围与缺失项见 Sampling SFT 专题笔记。经验候选数量：0。
