# 首轮数学 idea：时序多数据集 SFT
日期：2026-10-08。任务是新文本/领域数据陆续到来后的 SFT，不是数值时间序列预测。目标同时学习新内容、替换过时的当前答案、保留有效历史和未训练的通用能力。

初始冻结20张卡，加入独立的采样方差问题I21后保留21张推导记录。它们不是21个新算法。以下10个是待讨论的研究问题；已知投影、指数倾斜、Lie括号、方差分解等数学工具不作为原创。最终独立优先级见 priority-review.md（若尚未交付则为待完成）。完整公式、条件和证伪比较见 [math-cards.zh-CN.md](math-cards.zh-CN.md)。

| 卡 | 研究问题 | 数学切入点与决定性预测 |
|---|---|---|
| I01 | 当前与历史是否能无损分开更新？ | A=J_C N_H；目标在range(A)内才线性可行；目标所激发的小奇异值提高参数代价。 |
| I04 | 保护集合能否随事实有效期更新？ | 从保护协方差删去过时当前角色，加入仍正确的历史角色；是否释放有用方向必须测量。 |
| I05 | 没有旧任务数据，保留能力能否被证明？ | 若保护探针未覆盖允许的旧能力行空间，其零空间仍含未观测损伤方向。给出覆盖条件而非全能力保证。 |
| I09 | 局部保护为何在部分/近似保护时失效？ | 层变化XK+WD+XD；分析上游漂移WD的可补偿性。精确全模块保护可通过归纳组成全网保护，不能声称必然失败。 |
| I13 | 每轮很小的遗忘会否长期累积？ | 同一有效查询分布上的Hellinger路径上界为(sum sqrt(epsilon_t/2))²；比较固定锚点与逐轮锚点。 |
| I14 | 学生生成前缀会否漏掉旧能力分支？ | 固定基模前缀下的序列forward KL与学生采样测度不同；完整轨迹混合保证重要性权重上界。 |
| I16 | 保持旧分布是否过强，保持答对能否更省？ | 原生正确答案margin满足m+a·delta-L||delta||²/2>0时保留有限选项argmax；不是任意生成评分证书。 |
| I19 | “忘记历史”有多少其实是时间条件缺失？ | Bayes错误与H(Y|X,时间条件)；补充真实时间条件的理想logloss增益是条件互信息。 |
| I20 | 历史版本多是否必然耗尽LoRA容量？ | 固定线性残差的谱尾和输入兼容性，而不是版本数；比较相同总资源的检索/记忆。 |
| I21 | 平均梯度安全，随机批次仍会损伤旧能力吗？ | 旧KL二阶期望含tr(F Sigma)；固定同一平均目标，比较来源分层与随机来源计数。 |

可先讨论I04（语义有效期）、I21（固定均值下采样噪声）、I01（当前/历史可分离边界）。这是问题贴合度建议，不是原创审定或实验胜者；以独立优先级报告为后续讨论材料。
