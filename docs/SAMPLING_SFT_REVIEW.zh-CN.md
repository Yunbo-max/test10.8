## 为什么直接相关

本文同时关注新领域学习和原有能力保留。它保留普通 SFT 的交叉熵目标，通过 projection sampling 改变专家示范的表达分布，令数据更接近待训练模型。它不是按日期到达文本的 CPT，也没有在本轮所读实验中展示连续时间更新序列。

因此“先改写专家数据，使其更接近学生，再 SFT 减少遗忘”已经是直接相关方法，不作为本项目新颖性主张。本文是对当前来源审查的实质补充，不是本项目已经取得的结果。

## 理论对象与实现分别是什么

固定问题 q 和专家示范后，C 表示信息等价/正确的轨迹集合。论文的理想目标是

```math
p_C(y|q) = p_ref(y|q) 1[y∈C] / P_ref(C|q).
```

在支持受限于 C 的分布中，它最小化 KL(π || p_ref)。当 P_ref(C|q)>0 且相应采样假设满足时，理想 MH 核具有目标平稳分布，论文用数据处理不等式证明采样分布相对固定参考分布的 KL 不增。

这不是有限 SFT 后所有旧任务准确率不降的定理。数据分布接近参考模型与训练后模型能力保留是不同的对象；实际模型优化、任务变化与逐轮参考变化没有由此自动解决。

作者附录 C.2 明确将严格 MH 的接受比近似为“候选似然更高就接受”。所读 `boost_sci.py` 确认使用**无专家示范条件下、按 token 数平均的 log likelihood**做贪心比较，未执行完整正反 proposal 概率比和随机接受步骤。因此不能把作者默认实现称为已满足严格 MH 理论保证。

语义/正确性由包含专家示范的 proposal 提示促使保留。代码在生成最终轨迹后评分和记录正确性；所读采样循环未使用正确性作为每个候选的硬接受门槛。附录 C.1 报告的改写正确率也不是 100%。新事实、时间限定和历史答案能否完整保留，需要分别核查，不能默认为提示已经提供保证。

## 对当前目标最有用的证据

以下是论文 Table 1 的作者结果，准确率以百分数表示。本项目未复现。

| Qwen2.5-7B-Instruct 化学学习 | 化学测试准确率 | 五项原有能力均分 |
| --- | --- | --- |
| 原模型 | 34.3 | 59.7 |
| 普通 SFT | 61.8 | 52.0 |
| 单次改写后 SFT | 61.3 | 55.8 |
| OPSD | 61.8 | 56.8 |
| Sampling SFT | 66.0 | 58.6 |

“旧能力均分”是 MMLU、GPQA、AMC、MATH500、GSM8K 的准确率算术平均，不是“原本答对实例的保留比例”。Sampling SFT 平均仍比初始模型低 1.1 个百分点；AMC 从 42.2 降到 37.4，MATH500 从 73.4 降到 67.0。改善均值与每类旧能力都保留必须区分。

效果并非各设置都胜出：医学新任务 Sampling SFT 为 45.8，OPSD 为 46.6；Sampling SFT 的旧能力均分 51.6，仍低于原模型 59.7。附录 B 的 OLMo 化学新任务也略低于 OPSD，但旧能力均分更高。比较应保留完整新收益—旧损害关系。

论文提供单次改写对照以及不同采样步数，值得复用为简单比较对象。Figure 4 的有限 pass@k 差距支持多样本可解覆盖改善，但零次成功不是数学上的“原模型绝对无法解决”。

## 对我们三个研究切口的影响

| 现有切口 | 本文带来的帮助 | 仍需核查的研究问题 |
| --- | --- | --- |
| 时间敏感的选择性保留 | 给出数据侧方法与明确信息集合 C，而非只能修改训练损失 | 当新事实低概率、旧事实已过时，改写是否遗漏新事实或时间限定？ |
| 自然重现与逐轮遗忘 | 提供训练数据—参考分布距离这一补充解释 | 旧知识重复出现与数据分布相近分别起什么作用？单轮改善能否跨轮保留？ |
| 连续 CPT→SFT | 可用在监督示范侧，作为 CPT 后 SFT 的比较对象 | 每轮更新后应使用哪个参考模型？靠近当前模型是否仍能保住早期知识和未训练技能？ |

优先讨论的问题是：**每轮都使用更容易学习的监督数据，是否足以长期保留仍有效旧知识？若不足，失败是由新事实改写丢失、参考模型逐轮漂移，还是旧内容重现不足导致？**

这些是来源启发的研究问题，不是已经完成原创性裁决的新候选。不能只把单轮论文串成多轮、改个参考模型名称就宣布创新。最接近的连续学习、自蒸馏、知识更新与数据改写工作仍需审查。

## 对 2080 Ti 的启示

研究可借用“先处理训练数据、再普通 SFT”的模块化结构；发布实现不是本机直接执行配方。默认科学采样硬编码 7B 模型；训练示例使用 4×H100、bf16 FSDP，外部路径和令牌均为占位符。本机仍是用户确认的一张 22GB RTX 2080 Ti，Local 尚未测量环境与吞吐。

生成和评分成本应计入比较，而非只匹配 SFT 的训练步数。代码的 `block_num=58` 对 1856 tokens 得到 32-token 步长，勿将块数与论文公式中的块长混用。是否采用更小模型、何种原生后端和采样预算，需要测量及完整设计；不是本轮已批准的运行配置。
